# Bundled map data

`kyiv-districts.geojson` contains simplified administrative boundaries for Kyiv City's ten districts. It is bundled with the application so district context and hover highlighting do not depend on a third-party GIS request at runtime.

Source geometry is derived from OpenStreetMap data. © OpenStreetMap contributors. OpenStreetMap data is available under the Open Database License (ODbL).

The polygons are presentation context only. They do not represent incident extent, severity, strike coordinates, or evidence.
